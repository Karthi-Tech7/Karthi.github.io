# S. Karthikeyan - Portfolio

React + Vite portfolio. Edit `src/data/portfolio.js` to change any content.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
```

- Resume: replace `public/resume/S-Karthikeyan-Resume.pdf` (keep the file name).
- HackerRank: set `profile.hackerrank` in `src/data/portfolio.js`.
- Projects: edit or add objects in the `projects` array in the same file.
